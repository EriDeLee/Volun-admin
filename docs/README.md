## 阅读时保留的业务边界

- 服务时长由管理员以整数小时登记；签到签退不会自动折算时长。
- 报名、保存时长、下载材料均不会自动推进项目审核。
- 认定时长在审核结果公布后展示；未公布的 `null` 不能作为 0 小时处理。
- 地图选址、WPS 历史迁移、外部系统自动录入和附件3 生成尚未实现。
