# 正式用户的个人空间

正式用户导航包括“招募活动”（`/recruitment`）、“我的服务”（`/my-services`）和“个人信息”（`/profile`）。登录时，资料齐全进入招募活动，否则先进入个人信息；资料未齐全也可以浏览活动。

报名所需资料为姓名、学号 / 人员编号和已绑定手机号。姓名、编号沿用账号认证信息，缺失时由管理员核实补齐；手机号可在个人信息中绑定。点击报名时如资料不足，先进入个人信息，补全后点击“继续报名”返回原活动。公开报名页同样检查账号资料，后端拒绝资料不完整的账号提交，不能用表单中的姓名、学号和手机号绕过检查。未登录访客原有的手动问卷流程保留。

“我的服务”展示与本人账号关联的全部已报名项目，可筛选已参加和已报名待参加。本人有出勤或正数的已登记服务时长时计为已参加；报名不自动产生服务时长。认定时长仅在审核结果公布后展示。历史手动记录需由管理员核实关联账号后显示，不按姓名或学号自动认领。

`GET /api/v1/volunteer/projects` 要求有效登录并完成首次设密。响应 `data.items` 中每项包含 `project`（公开项目信息）、`form_id`、`deadline`、`registered`、`participated`、`recognized_hours`。仅返回已审批且开放招募的项目，或与当前账号绑定的已审批项目。招募截止、撤回发布或项目离开筹备 / 招募阶段后不再提供报名入口。未公布的认定时长为 `null`，响应不包含内部账号标识、其他成员或完整工作流。
